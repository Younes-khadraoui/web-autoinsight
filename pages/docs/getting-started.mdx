# Welcome to Autoinsight

This package is designed to make data analysis easier for data analysts by automating the process using large language models (LLMs).

## Installation

To install the AutoInsight package, use the following command:

```bash
pip install autoinsight
```

## Features

- **Automated Data Analysis:** Perform comprehensive data analysis with just a few commands.
- **Insight Generation:** Automatically generate insights and summaries from your data.
- **Report Creation:** Create detailed and customizable reports based on your analysis.
